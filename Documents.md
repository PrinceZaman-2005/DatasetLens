# DatasetLens🔍
Open-source dataset inspection and quality analysis toolkit for ML datasets.

---

# Current Features:
1. Text inspection and analysis


## Text Inspection:
### Detect files:
.txt, .csv, .json, .jsonl, .xml, .md, .tsv, .yaml, yml
### Encodings:
UTF-8, UTF-16, ASCII, Latin-1, CP1252
### Languages:
English, Spanish, French, etc.

### Text Analysis:
- Single file inspection
- Directory inspection
- Metadata generation
- Format detection
- Supported format validation
- Unsupported file detection
- Encoding detection
- Language detection
