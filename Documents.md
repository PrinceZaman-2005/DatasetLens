# DatasetLens 🔍

**Open-source dataset inspection and quality analysis toolkit for Machine Learning datasets.**

---

## Current Features

### 1. Text Inspection and Analysis

#### Supported Formats

* `.txt`
* `.csv`
* `.json`
* `.jsonl`
* `.xml`
* `.md`
* `.tsv`
* `.yaml`
* `.yml`

#### Supported Encodings

* UTF-8
* UTF-16
* ASCII
* Latin-1

#### Language Detection

* English
* French
* Spanish

 And more

#### Text Analysis Capabilities

* Single file inspection
* Directory inspection
* Metadata generation
* Format detection & distribution analysis
* Supported format validation
* Unsupported format detection
* Encoding detection& distribution analysis
* Language detection & distribution analysis

---

### 2. Image Inspection and Analysis

#### Supported Formats

* `.jpg`
* `.jpeg`
* `.png`
* `.bmp`
* `.webp`
* `.tiff`

#### Image Analysis Capabilities

* Single file inspection
* Directory inspection
* Image format detection & statistics
* Corrupt image detection
* Supported format validation
* Unsupported format detection

**Note:** Current version supports standard TIFF image inspection. Advanced TIFF and volume-oriented inspection are planned for future releases.
